Aceray Redesign Overview

A modern, high‑performance static site built with Vite, showcasing the premium furniture catalog while preserving the existing WordPress CMS for content authoring.

View Catalog

Architecture Diagram

The site is a static front‑end (Vite) that pulls content via the WordPress REST API. All assets are hosted on a static CDN (GitHub Pages, Firebase Hosting, or Netlify).

Design System

  • Primary Color: #718f80
  • Typography: Montserrat (Google Font) – headings use var(--font-primary) with weight 600.
  • Spacing: 8pt grid (4px, 8px, 12px, …) – defined in --space-* tokens.
  • Buttons: .button-primary (solid sage green) & .button-outline (transparent with green border).

CMS Integration

Content editors continue to use the existing WordPress installation. The static site fetches product data (title, image, description, price) via the WordPress REST endpoints during the build step (or at runtime with client‑side fetch for dynamic sections).

Next Steps

  1. Configure the WordPress REST API credentials (read‑only token).
  2. Run npm run build to generate the production bundle.
  3. Deploy to the chosen static host (GitHub Pages, Firebase Hosting, Netlify).
  4. Provide the client with this deck for review and feedback.
